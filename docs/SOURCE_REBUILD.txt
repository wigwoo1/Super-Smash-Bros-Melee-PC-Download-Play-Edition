Open an x86 Visual Studio Developer Command Prompt with CMake, Ninja, Clang/Clang++, Python and Rust available. Rust needs the i686-pc-windows-msvc target. From this desktop package, choose a new, short build root:
  set "MELEE_BUILD_ROOT=%USERPROFILE%\Documents\Codex\melee-build"

1. Generate the private font inputs from your local disc copy:
  python source/tools/extract_pc_fonts.py "native-preview/data/melee.nkit.iso" "%MELEE_BUILD_ROOT%\fonts"

2. Build the native runtime:
  python rebuild-native-runtime.py --build-dir "%MELEE_BUILD_ROOT%\runtime"

3. Build the game library with the same Release configuration:
  python rebuild-native-library.py --build-type Release --generated-includes "%MELEE_BUILD_ROOT%\fonts" --build-dir "%MELEE_BUILD_ROOT%\game"

4. Link into a new output folder:
  python link-game-audit.py --runtime-build "%MELEE_BUILD_ROOT%\runtime" --game-library "%MELEE_BUILD_ROOT%\game\melee.lib" --output "%MELEE_BUILD_ROOT%\output\melee.exe" --no-saves

Commands above describe the standard layout. The tested machine-specific command records in development/source-rebuild-20261016 use explicit tool paths and an explicit dependency-source map.
