NATIVE DIAGNOSTIC LIBRARY REBUILD

This entry point builds the modified x86 static library only. It does not
link a playable executable. Full runtime/package rebuild remains unfinished.

Prerequisites: Windows, an x86 MSVC developer command prompt with Windows SDK,
Clang on PATH, CMake 3.20 or newer, Ninja, and Python 3. These tools are not
bundled by this script. Open the x86 developer prompt, change to the package
folder, then run:

  python rebuild-native-library.py

Paths resolve relative to the script, including when the package is moved.
The package uses source/ and dependencies/aurora/. The development checkout
uses melee/ and aurora/. Build output defaults to build-native-library/.
Use --configure-only to check configuration or --build-dir to choose output.
--build-type selects Debug (default), Release, or RelWithDebInfo. Select the same
configuration family as the Aurora runtime: Debug uses a different C++ runtime
and cannot be mixed with Release dependency outputs.

Without local font includes, the two original font translation units remain
excluded by the existing CMake configuration. For a library including them,
extract locally from your own supported USA revision 2 disc image:

  python source/tools/extract_pc_fonts.py "YOUR_DISC_IMAGE" "LOCAL_FONT_FOLDER"
  python rebuild-native-library.py --generated-includes "LOCAL_FONT_FOLDER"

In the development checkout replace source/tools with melee/tools.
The extractor reads the image without modifying it and verifies the DOL
checksum before writing fonts. Generated fonts are original asset data;
keep them local and do not include them in source distribution packages.

Other historical scripts may still require the original workspace layout.
Do not use a passing library build as evidence of playable release acceptance.
Explicit tool paths are supported with --cmake, --ninja and --clang when PATH discovery is unavailable. The Windows SDK and MSVC environment are still required.

Verified 2026-10-07: clean compilation from the desktop packaged source passed all 1008 steps with warnings. Default configuration excludes local disc font translation units. Evidence: native-package-library-build-evidence.json. This does not verify a full executable rebuild or playable release.

Diagnostic link entry point: link-game-audit.py accepts --runtime-build (an existing Aurora Ninja build), --game-library (a compiled game library including the local fonts), and --output (diagnostic executable path). It does not launch the output. It uses the compiler from the selected runtime cache and requires the x86 MSVC/SDK environment. The Aurora build must contain the examples/simple.exe dependency rule. The optional melee_disc_smoke.exe rule supplies DVD dependencies when present; otherwise the configured nod library is resolved from the selected build. A clean packaged Aurora rebuild remains unverified. The default library built without local fonts is not sufficient for a complete original-game link.
