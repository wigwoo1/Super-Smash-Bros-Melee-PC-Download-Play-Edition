Requires Python3.11 or newer. No extra Python packages required.

Inputs: the inspected Melee HD Texture Pack archive and textures-mapping-audit.json
produced by the native filename parser audit. The tool verifies the archive SHA256.
Default imports only GALE01/main mappings. Add --include-optional to also import
approved character, item and casual-stage base textures (5214 mappings total, including
2949 additions). Main artwork wins12shared-key item alternatives;five conflicting main
keys remain excluded and identical duplicates are collapsed. Add --include-mips to preserve
compatible authored mip chains (45sidecar PNGs across5chains in this inspected release).

may share its mip chain only after full base-file SHA256 equality;output names follow the
chosen base. Three MushroomKingdomIIchains have incompatible dimensions (640base vs64mip1,
expected320) and remain excluded without resizing. Another27sidecars depend on unresolved
base choices. Base images stay usable. Standalone character renders still need UI mappings.
